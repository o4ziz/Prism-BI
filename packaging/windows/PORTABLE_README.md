# Prism BI 1.0.0 — Portable

This folder is a ready-to-run Windows build. **No source code is included.**

## Run

1. Keep this whole folder together (`PrismBI.exe`, `_internal`, `plugins`, `samples`).
2. Double-click `PrismBI.exe`.

Do **not** copy only the `.exe` — Windows will fail to start the app.

## Sample project

**File → Open Project…** → `samples\SalesDemo.prism`

## Notes

- User settings/logs: `%USERPROFILE%\.prism-bi\`
